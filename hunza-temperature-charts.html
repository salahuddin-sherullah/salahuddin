Gilgit Baltistan Temperature Anomalies

Monthly variation and long-term temperature patterns relative to the 1991–2020 average · Jan. 1940–Aug. 2026

Note: This is ERA5 monthly-averaged reanalysis data for the Gilgit-Baltistan region (extracted via bounding box), model output rather than ground-observed temperature. This grid resolution (~28km) blends valley floors with surrounding high peaks, giving cells a cold bias in this terrain, so anomaly values (deviation from the 1991–2020 baseline) are meaningful, but absolute °C values should not be read as real-world temperatures for any specific location.

Source: ERA5
